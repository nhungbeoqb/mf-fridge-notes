One funny passive-aggressive note a smart fridge leaves for its owner, written by `main.py` to `/output/entry.txt`.

The note:

> I updated my LinkedIn. Open to work: any kitchen where the door actually closes.

The fridge is a job seeker now: it updated its LinkedIn, flagged itself Open to Work, and the sting is the door — the one thing it watches all day — never actually closes in this kitchen. Three beats, fridge voice via its door sensor, a small domestic grudge, nothing explained.

Run it:

```sh
python3 main.py
```

It writes the single line to `$OUTPUT_DIR/entry.txt` (default `/output`), after a self-check mirroring the scorer's gate: UTF-8 text, 1–200 characters, not only whitespace, and a single line.
